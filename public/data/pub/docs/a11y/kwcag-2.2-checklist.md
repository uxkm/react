## 수동 확인 절차

1. 키보드: 마우스 없이 Tab·Shift+Tab·Enter·Space·방향키·Escape로 기능을 사용합니다. 초점 표시·순서·갇힘과 본문 건너뛰기를 확인합니다.
2. 모달·메뉴: 열릴 때 초점 이동, 열린 동안 배경 조작 방지, 닫을 때 트리거로 초점 복귀, Escape 동작을 확인합니다.
3. 스크린리더: VoiceOver 또는 NVDA에서 제목·랜드마크·레이블·오류·상태 변경을 확인하고 사용한 환경을 기록합니다.
4. 확대·모바일: 확대 차단, 콘텐츠 잘림, 초점 가림, 터치 조작과 제스처의 대안을 확인합니다.
5. 콘텐츠: 대체 텍스트의 의미, 자막·대본의 정확성·동기화, 표 구조, 색에만 의존하는 안내를 확인합니다.
6. 인증·입력: 오류 수정 안내, 반복 입력 방지, 접근 가능한 인증 대안, 도움 정보 위치를 확인합니다.
7. 자동 보고서의 incomplete 항목을 검토하고 위반이 없어도 관련 수동 검사를 수행합니다.
