# 최초 적용 시 검사 현황

검사일: 2026-11-09. 적용 범위와 명령은 [접근성 검사 운영](./README.md)을 참고하세요. 이 기록은 전체 사이트의 준수 판정이 아닙니다.

## 후속 정리

- `npm run lint`: 오류 0건·경고 0건. `--max-warnings=0`으로 새 경고를 차단합니다.
- `npm run lint:a11y`: 정적 접근성 진단 0건.
- React `refs`, `set-state-in-effect` 경고 수준 예외를 제거하고 권장 오류 규칙을 적용했습니다.
- 제어 상태·ref 갱신·키보드 업로드·Escape·메뉴 액션·스크롤 영역을 정리했습니다. Next.js 프로덕션 빌드·타입 검사와 데스크톱·모바일 상호작용 12개가 통과했습니다.
- HLS는 실제 WebVTT 자막이 포함된 공식 샘플로 교체했고, 브라우저에서 영어 트랙이 showing 상태인 것을 확인했습니다. 런타임 매니페스트 자막을 인식하지 못하는 정적 규칙만 근거를 명시해 해당 태그에서 예외 처리합니다.
- 아래 숫자는 도구 최초 적용 당시의 기록입니다. 정적 진단 0건은 브라우저 접근성 위반 0건을 의미하지 않습니다. 최신 브라우저 결과는 `reports/a11y/summary.md`에서 확인합니다.

## 최초 실행 결과

- 프로덕션 빌드와 타입 검사: 통과.
- 일반 ESLint: 오류 0건. 기존 React 진단 36건과 접근성 진단 57건을 경고로 표시.
- `npm run lint:a11y`: 접근성 정적 진단 57건으로 실패. 경고를 무시하지 않고 전용 명령에서 실패로 취급합니다.
- `npm run test:a11y`: 20개 화면·환경·상태 중 15개 통과, 5개 실패. 실제 위반으로 실패하며 테스트를 건너뛰거나 규칙을 제외하지 않았습니다.

| 남은 대상 | 환경 | 주요 자동 진단 |
| --- | --- | --- |
| `/pub` | 데스크톱·모바일 크기 | 장식 배지의 금지된 ARIA, 표·행의 부모/자식 관계, 스크롤 헤더 초점 |
| `/pub/guide/input` | 데스크톱·모바일 크기 | 작은 클릭 영역 (`target-size`) |

상세 위치와 재현 자료는 `reports/a11y/summary.md`, `summary.json`, `lint.json`, HTML 보고서를 확인합니다. 환경과 상태가 겹치는 동일 노드는 중복 집계될 수 있습니다.
