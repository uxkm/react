## 범위와 판정 기준

정적 HTML 166개와 메인 섹션 쿼리 프리뷰 7개를 대상으로 합니다. 루트와 `/b2b/main`은 리다이렉트 완료 후 도착 화면을, `/404`와 `/_not-found`는 오류 화면을 검사합니다. 라이트·다크와 데스크톱·모바일 조합으로 문서 전체를 검사하므로 헤더·탐색·본문·푸터를 포함합니다.

전체 경로와 소스 분류는 [검토 인벤토리 JSON](site-inventory-2026-11-14.json)에 기록했습니다. 166개 정적 경로 중 75개는 현재 준비중 안내 화면입니다.

소스 범위는 공통 `src/components`, B2B `src/widgets`·`src/modules`·`src/screen/b2b`, PUB 목록·가이드·데모 및 공통 라우터입니다. 기본 UI 64개 파일의 상세 결과는 [공통 컴포넌트 검토](component-review-2026-11-14.md)를 함께 확인합니다.

기준은 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)와 [WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/)입니다. axe-core의 WCAG A·AA 결과, 별도의 권장 사항(best practice), 수동 판정 대상(incomplete)을 구분합니다. 자동 검사 통과를 접근성 인증이나 모든 스크린리더 지원으로 해석하지 않습니다.

## 초기 초점 후속 수정

Modal·Drawer는 기본으로 제목(h2, tabindex=-1)에 초점을 둡니다. 제목이 없거나 비어 있으면 전체 시각 패널(tabindex=-1)에 둡니다. FullMenu·PUB 필터·비고 레이어도 같은 공통 훅을 사용하며, 버튼으로 여는 비모달 Popover에도 같은 제목/패널 기준을 적용합니다. initialFocusRef로 지정한 유효한 내부 요소는 우선하며, 숨겨졌거나 비활성인 대상은 기본 제목/패널로 대체합니다. staticDemo는 초점을 자동 이동하지 않습니다.

제목을 일반 Tab 진입점으로 추가하지 않고, 제목에서 Tab·Shift+Tab을 누르면 DOM 순서에 따른 다음/이전 조작 요소로 이동합니다. 경계에서는 내부를 순환합니다. 가이드에서 ‘제목 표시’와 ‘초기 초점을 입력으로 지정’을 각각 확인할 수 있습니다.

후속 검증: 키보드·초점 회귀 72개와 Modal·Drawer·Popover의 테마·기기별 자동 검사 12개를 통과했습니다. 전체 ESLint와 프로덕션 빌드도 통과했습니다.


## 탭 선택 후속 수정

Tabs 가이드의 HTML 마크업 프리뷰가 정적 버튼으로만 구성되어 선택·방향키 이벤트가 없던 문제를 수정했습니다. 프리뷰는 공통 Tabs 컴포넌트를 사용하며, HTML 코드의 구조 예시와 실행 프리뷰를 구분합니다. 스크롤 전용 네비게이션은 ‘탭 목록 왼쪽/오른쪽으로 스크롤’, 실제 선택 네비게이션은 ‘이전 탭/다음 탭’으로 이름을 구분합니다.

전체 가이드 탭 예시의 방향키·Enter·Space 선택, Tab의 패널 진입·재진입, 이전·다음 선택 및 스크롤, 라이트·다크 자동 검사 12개를 통과했습니다. ESLint와 프로덕션 빌드도 통과했습니다.
