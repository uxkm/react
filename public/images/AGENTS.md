# 이미지 보관 규칙

- 예시·샘플·데모·임시 콘텐츠용 이미지는 `public/images/@dummy/`에 보관한다.
- 코드와 예제에서 해당 이미지는 `/images/@dummy/파일명` 경로로 참조한다.
- 실제 서비스용 아이콘·공통 이미지·페이지 이미지는 용도에 맞는 기존 폴더에 보관한다.
- 이미지를 이동하거나 이름을 변경할 때 실제 사용 경로와 가이드의 예제 코드도 함께 수정한다.

- `public/images/icon/` 안의 아이콘 파일명은 `ico_`로 시작한다(예: `ico_check.svg`). 파일형 Icon에는 실제 파일명(`src="ico_check.svg"` 또는 `name="ico_check.svg"`)을 전달한다. 코드에 내장된 아이콘의 `name="check"` 등은 별도 이름 체계를 유지한다.
